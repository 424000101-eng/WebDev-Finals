UI/UX Specifications

This application overrides native Bootstrap CSS variables inside custom.css to build a customized premium environment.

  • Theme Color: Emerald Green Accent (--bs-primary: #10b981)
  • Background: High-contrast Slate Dark Mode (--bs-body-bg: #0f172a)
  • Typography: Plus Jakarta Sans sans-serif layout system
  • Components: Glassmorphic blurs, animated transitions, and fluid grid break alignments.
Backend Server Architecture

Form actions point downstream to a standalone server-side handler routine built on PHP configuration runtimes.

  • Data Transfer: Global $_POST array collection endpoints.
  • Sanitization: String security cleaning via htmlspecialchars() parameters.
  • Validation: Enforces mandatory completion logic across name, email, subject, and message structures.
  • Length Constraints: Enforces a strict minimum requirement of 20 characters for input message blocks.
